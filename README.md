## 📧 Email Spam Classification Engine

<a href="https://github.com/amanmani07/spam-classifier">
<img src="https://img.shields.io/badge/VIEW%20PROJECT-00D9FF?style=for-the-badge&logo=github&logoColor=white"/>
</a>

An end-to-end Natural Language Processing system designed to automatically classify messages as **Spam or Not Spam**.

### 🔬 Machine Learning Pipeline

```text
                    RAW EMAIL / MESSAGE
                            │
                            ▼
                  TEXT PREPROCESSING
                            │
                            ▼
                    TF-IDF VECTORIZATION
                            │
                            ▼
               MULTINOMIAL NAIVE BAYES
                            │
                            ▼
                   SPAM CLASSIFICATION
                            │
                            ▼
                    FINAL PREDICTION
```
